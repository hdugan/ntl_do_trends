# ntl_do_trends

Selected figures and their generating R scripts from the North Temperate Lakes
long-term record analysis (NTL-LTER, EDI packages 1, 29, 35). Split out from
the main `BuoyExploration_Mendota` project.

Run in order: `00_pull_data.R` pulls the newest revision of each needed EDI
data package (via `EDIutils`) into a local `data/` folder (gitignored, not
included here); `01_plot_profiles.R` plots every individual profile so
sensor glitches are visible; `02_clean_profiles.R` removes the ones that
are physically implausible, writing `data/profiles_clean.csv` (the raw
`data/profiles.csv` is left untouched). The fig*.R scripts then read
`data/profiles_clean.csv` and write their PNG(s) to `figures/`.
`Figure2_clarity_trends.R` must run before `Figure1_rate_of_change.R`,
which reads `figures/fig02_trends_table.csv` for its DOC/Secchi arrows.

| Script | Figure(s) |
|---|---|
| `00_pull_data.R` | (no figure) — downloads `data/profiles.csv`, `chem_north.csv`, `secchi.csv`, `color.csv`, `chl.csv`, `lake_levels.csv` from EDI (NTL-LTER packages 29, 1, 31, 87, 35, 30). `lake_levels.csv` covers the 7 northern lakes only (AL, BM, CB, CR, SP, TB, TR) — not currently used by any figure script |
| `01_plot_profiles.R` | `figures/diagnostics/diag_<lake>_<bin>_profiles.png` — every individual temp & DO(%sat) profile, per lake x half-month bin (same bins as fig12), baseline (pre-2016) vs recent (2016-2025) |
| `diagnostic_metadepths.R` | `figures/diagnostics/diag_<lake>_<year>_metadepths.png` — faceted temperature profiles for one lake-year (edit `LAKE`/`YEAR` at the top) with dashed lines at that cast's own `rLakeAnalyzer::meta.depths()` metalimnion top/bottom, or no lines where the cast was classified as mixed/isothermal. Sanity-checks the thermal-zone classification used by `TableS2_ZoneTrends.R` |
| `02_clean_profiles.R` | (no figure) — for lakes with zmax > 10 m, removes unrealistic bottom-point jumps (temp up >5°C or DO up >20 %sat at the single deepest reading vs the next-shallowest); plus manual removals: one bad-sensor DO profile (Sparkling 2004-08-16) and all temp/DO for Crystal Lake 2012-2013 (whole-lake mixing experiment); writes `data/profiles_clean.csv` and logs removed points to `data/profiles_removed_points.csv` |
| `FigureSX_do_heatmaps.R` | `figSX_northern_do/sat.png`, `figSX_southern_do/sat.png` — depth-time DO heatmaps, northern vs southern lakes |
| `Figure2_clarity_trends.R` | `fig02_clarity_trends.png` — standardized (robust z-score, median/MAD) water-clarity trends, all 11 lakes: Kd/DOC/Secchi for the 7 northern lakes, DOC/Secchi only for the 4 southern lakes (no Kd data there). CDOM colour (EDI 87, a440) is deliberately excluded. Also writes `figures/fig02_trends_table.csv` (lake x metric slopes with p-values) |
| `Figure1_rate_of_change.R` | `fig01_rate_mgL.png`, `fig01_rate_sat.png` — Theil-Sen trend heatmaps by depth & season, all 11 lakes. The DOC/Secchi arrows beside each lake name are read from `figures/fig02_trends_table.csv` rather than fit here — **run `Figure2_clarity_trends.R` first** |
| `Figure3_o2_profiles.R` | `fig03_o2_profiles.png` — August DO (% saturation) depth profile, all 11 lakes, four overlaid decade medians (1985-1995 / 1995-2005 / 2005-2015 / 2015-2025, blue->green->orange->red). No annotations (no anoxic-boundary markers, no metalimnetic-O2-max diamonds) — just the raw profile shape across decades. Panels built individually + assembled with patchwork (not facet_wrap) so the gap left by the 7th northern lake is a true blank space and the legend is extracted once and placed manually. Independent of the other two `Figure*.R` scripts. Also writes `fig03_o2_profiles_leveladjusted.png` — Crystal/Sparkling/Big Muskellunge only, same decade medians but with each cast's depth adjusted for that day's interpolated lake level (`data/lake_levels.csv`, EDI 30) referenced to the lake's own long-term median level, so depth reads as distance below the long-term average surface rather than below whatever the surface was that day |
| `Figure4_chl_profiles.R` | `fig04_chl_profiles.png` — August chlorophyll profile shift (1995-2005 vs 2016-2025), 4 northern deep oligotrophic lakes, one row |
| `Figure5_habitability.R` | `fig05_habitability.png` — habitability by depth window, all 11 lakes, one shared-depth-axis "core sample" per lake side by side. Per lake x depth bin (0.5 m <10 m zmax, 1 m otherwise, same rule as `Figure1_rate_of_change.R`), compares median August DO (mg/L) baseline (pre-2016) vs recent (2016-2025) against a 3 mg/L habitat threshold: dark red = remained hypoxic, orange = newly hypoxic, green = newly oxygenated, blue = remained oxygenated. Blank = <4 years of August data in either era. Independent of the other `Figure*.R` scripts |
| `FigureSD_BM_o2sat.R` | `figSD_BM_o2sat_1996-05.png` (+ legend) — Big Muskellunge O2 saturation panel |
| `FigureSX_metalimnionwindow.R` | `figSX_metalimnion_window.png` — the metalimnion as a "ribbon through time," all 11 lakes, full 1981-2025 record. Same per-cast classification and eligibility rule as `TableS2_ZoneTrends.R` (`rLakeAnalyzer::meta.depths`; resolved top+bottom AND positively stratified only), but instead of a seasonal climatology the x-axis is real calendar time: each year's run of eligible casts draws its own ribbon polygon (metalimnion top to bottom), colored by year (viridis), so 45 years render as a sequence of pulses with gaps where the lake wasn't resolvably stratified. Shows the raw signal for Crystal Bog/Wingra too (unlike the table, which overrides them to a fixed shallow split) — their sparse/unstable pulses are a visual check on why that override was needed |
| `Figure_map.R` | `figMap_regions.png` — site map, two side-by-side regional panels (real basemap tiles via `maptiles`/Esri World Light Gray Canvas): Dane County lakes (southern, 4 lakes) and Vilas County lakes (northern, 7 lakes). Each study lake's actual shape is filled light blue from the NHD polygons in `data/GIS/NHLDshp` (no shapefile for Fish Lake, so it stays a plain point). Southern panel carries a small orthographic globe inset locating Madison, WI globally. Needs an internet connection to download tiles at run time. Independent of the other `Figure*.R` scripts |
| `TableS1_Characteristics.R` | `tables/TableS1_Characteristics.tex` — downloads static lake-characteristic data (location, morphometry, drainage/trophic classification) for the 11 study lakes from EDI 434 (`data/lake_characteristics.csv`) and formats it as a LaTeX table (region, then descending max depth, matching the other figures' lake ordering). Static descriptors only, not the time-series data the other scripts analyze; independent of everything else here |
| `TableS2_ZoneTrends.R` | `tables/TableS2_ZoneTrends.tex` (+ `.csv`) — Theil-Sen trend per decade by lake x THERMAL zone instead of a fixed depth grid: each cast's own temperature profile is classified into Spring Mixing / Epilimnion / Metalimnion / Hypolimnion / Fall Turnover via `rLakeAnalyzer::meta.depths` (isothermal casts become Spring Mixing or Fall Turnover, split at day-of-year 200), so "hypolimnion" tracks that day's real thermocline depth rather than a fixed metre cutoff. Mann-Kendall significance, Benjamini-Hochberg FDR-corrected per lake across its ~15 zone x variable tests (vs. Figure1's ~14k-cell fine grid) -- pooling to physically real zones is what actually recovers power, not the correction method. Reads `data/profiles_clean.csv` directly; independent of `Figure1_rate_of_change.R` though it answers the same question at coarser, better-powered resolution |

`Figure1_rate_of_change.R` (6.5x8in), `Figure2_clarity_trends.R` (6.5x6in),
`Figure3_o2_profiles.R` (6.5x6in), and `Figure4_chl_profiles.R` (6.5x2.7in), all 500dpi, don't
draw an overall title/explainer on their PNGs — that text is written instead to the shared
`figures/captions.csv` (columns: file, title, caption; each script merge-writes its own rows
without clobbering the others').
